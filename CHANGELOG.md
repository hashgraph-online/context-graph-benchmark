# Changelog

## 0.1.0

The initial release includes the Python SDK, JSONL adapter protocol, public query suites, one-hour and 24-hour agent workloads, a nine-component scorer, and a local and offline dashboard. The reference study measures CIGAR, NetworkX and LeanCTX. Run `cgb reference verify` to check the scores against the packaged measurements. [Reference scorecard](docs/reference-study.md)
