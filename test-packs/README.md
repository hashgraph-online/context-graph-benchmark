# Community pack examples

These declarative examples are public development data. They are not installed or promoted automatically. Validate, run deterministic conformance, then register explicitly with `cgb test-pack register`. Runtime discovery reads `.cgb/test-packs/`; installed contributor JSON cannot execute code or change core scoring.

See [the contract and recipe](../docs/test-pack-spec.md). Keep case data licensed, disclose affiliations and use your own namespace. New versions do not overwrite old reports. New execution drivers require reviewed source changes to the trusted dispatcher and conformance/offline replay tests.
