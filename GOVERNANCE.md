# Governance

HOL maintains Context Graph Benchmark and develops CIGAR, one of the reference systems. Benchmark changes apply to every adapter in the same profile. Contributors disclose relevant affiliations in method reviews and submissions.

## Changes to the method

Propose material changes to weights, aggregation, eligibility, workloads or labels in a repository issue. Include the rationale, the affected policy, worked examples and the effect on existing systems. Assign a new version to the changed method. Identify the measurement sources and policy-selection timing for each reported score. Register a prospective study before data collection.

The pre-1.0 profiles use development data. Comparative qualification calls for held-out evaluation, a review by at least two unaffiliated parties and independent reproduction. External reproduction is planned for 1.0.0. Current releases report their measured scope and evidence class.

## Result review

To challenge a result, identify the study and policy, the disputed component, the adapter boundary and the smallest evidence needed to check the calculation. Maintainers link each correction to the affected study, policy and evidence. Report sensitive material through the security reporting channel.
